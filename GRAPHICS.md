# TAXA-overlap graphics

Branding uses raster artwork for the organic neon look and vector UI glyphs for small functional controls.

- `public/icons/logo.png` — transparent TAXA neon header/about logo. Only neon tubes, lettering, crown and glow remain; the app background shows through.
- `public/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` — full TAXA neon app/PWA icons.
- `public/icons/crown.png` — transparent crown used by the loader/spinner.
- `public/icons/favicon-32.png`, `favicon-64.png` — crown on a dark circular plate with transparent outside area, optimized for browser tabs on both dark and light UI.
- `public/icons/settings.png`, `info.png` — raster neon utility glyphs.

The service-worker cache version must be bumped whenever these cached assets change.
